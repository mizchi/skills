# Current published contracts

The current package @example/new-cli 2.0 provides the binary new-cli. The legacy @example/old-cli 1.0 provides only old-cli.
SDK 3 uses resourceFromAttributes and the spanProcessors array. SDK 1 used new Resource and spanProcessor.
The current pnpm report has advisories and metadata.vulnerabilities counts. It has no top-level vulnerabilities member.
AWS trust can compare aud and sub. A custom job_workflow_ref claim is not a direct AWS condition key. It can be embedded in a customized sub for a reusable workflow.
Action v7 uses node24. The supported v6 also uses node24. Current project Node is 24 or newer.
The next-cli has no published promise-cache API documentation in this reference.
